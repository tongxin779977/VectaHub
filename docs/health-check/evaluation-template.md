# 评估报告输出模板

本文档定义模块健康度评估报告的标准输出格式。

## 报告结构

每个模块的评估报告包含以下部分：

1. 基本信息
2. 总分与等级
3. 维度评分明细
4. 关键发现
5. 改进建议
6. 标杆亮点

---

## 评估工具

### 推荐检查命令

```bash
# 统计文件行数
find src/[module] -name "*.ts" -not -name "*.test.ts" | xargs wc -l | sort -n

# 统计测试文件数量
find src/[module] -name "*.test.ts" | wc -l

# 搜索 any 类型
grep -rn ": any" src/[module] --include="*.ts" | grep -v ".test.ts"

# 搜索 default export
grep -rn "export default" src/[module] --include="*.ts"

# 搜索 export let
grep -rn "export let" src/[module] --include="*.ts"

# 搜索 TODO/FIXME
grep -rn "TODO\|FIXME\|HACK" src/[module] --include="*.ts"

# 搜索未使用的导入
# 需要使用 ESLint 或 TypeScript 编译器
```
