# Backlog

> Document Status: Current Backlog Directory
> Authority: Navigation for the split development backlog.

This directory stores the operational backlog for NL Workflow Orchestrator development.

## Files

| File | Responsibility |
|------|----------------|
| [protocol.md](./protocol.md) | Task selection, locking, status transitions, verification evidence, and multi-subagent workflow. |
| [automation-prompt.md](./automation-prompt.md) | Copyable prompt for recurring automation runs. |
| [cross-project-template.md](./cross-project-template.md) | Rules for adapting this backlog system to another project. |
| [items/](./items/) | One current backlog item per file. |
| [history/](./history/) | Optional archive for resolved historical findings. |

## Usage

Use [../development-backlog.md](../development-backlog.md) as the stable entry point.

Automation agents must read [protocol.md](./protocol.md) before selecting or modifying any item file.
