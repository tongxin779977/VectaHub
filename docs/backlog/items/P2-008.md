# P2-008: Artifact handoff 合同与最小实现

> Status: done
> Priority: P2

> Module: `src/orchestration-plan/artifact-storage.ts`, `src/types/artifact.ts`
> Completed: 2026-06-08

## Description

The orchestration path needs a minimal artifact-handoff contract so generated artifacts can be persisted, linked back to producing execution/task identifiers, and handed across plan, draft, and execution stages through stable references.

The artifact storage and handoff primitives were already implemented and tested, but the backlog item file was missing.

## Expected

- Define runtime types for artifact references, handoff links, and handoff records.
- Persist artifact metadata and redacted artifact content.
- Support artifact lookup, listing, deletion, and execution/task filtering.
- Create and update artifact handoff records between plan, draft, and execution stages.

## Scope

- In-scope: artifact reference contract
- In-scope: artifact storage and retrieval
- In-scope: handoff record creation and artifact-link updates
- In-scope: artifact validation and redaction
- Out-of-scope: remote artifact storage
- Out-of-scope: workflow-engine level automatic artifact consumption

## Verification Plan

1. Artifacts can be created, retrieved, listed, and deleted.
2. Handover records can be created and linked to artifact references.
3. Invalid artifact references are rejected by validation.
4. Stored artifact content and metadata are redacted before persistence.
