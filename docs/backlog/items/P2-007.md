> Status: done

## Description

Delegate-style workflow steps need a real agent runtime bridge instead of type-only support, so the workflow engine can resolve agent descriptors, run agent preflight before execution, pass prompt input with the correct transport, and normalize delegated worker results into the existing execution contract.

The delegate handler, registry, adapters, and worker-result normalization already existed, but the workflow execution path was missing runtime preflight wiring and stdin prompt transport support. This round completed that execution bridge and added regression coverage.

## Expected

- Workflow `delegate` steps resolve a known agent descriptor and adapter.
- Delegate execution runs agent preflight before the actual delegate command.
- Prompt transport, including stdin-based transport, reaches the delegated runtime correctly.
- Delegate results normalize into the worker-result contract used by downstream execution and recovery logic.

## Scope

- In-scope: workflow delegate runtime wiring
- In-scope: delegate preflight before spawn
- In-scope: stdin prompt transport support
- In-scope: workflow-engine level delegate dependency injection
- Out-of-scope: UI agent configuration management
- Out-of-scope: remote multi-agent orchestration

## Verification Plan

1. Delegate steps fail fast when agent preflight fails.
2. Delegate steps execute only after successful preflight.
3. Stdin-based prompt transport reaches the execution layer.
4. Draft execution still works with the delegate-enabled workflow engine path.
