## Description

The semantic acceptance system needs a standardized score report so NL quality can be evaluated with consistent dimensions, pass/fail thresholds, grouped statistics, failed-case detail, and a stable markdown summary for review workflows.

The scoring model and report renderer were already implemented and tested, but the backlog item file was missing.

## Expected

- Produce a structured semantic report with total/pass/fail counts, pass rate, and average score.
- Include standardized dimensions for intent correctness, plan quality, safety correctness, output contract, user usefulness, and recovery awareness.
- Render a stable markdown report with summary, dimension scores, grouped statistics, failed details, and verdict.
- Keep report generation deterministic for the same evidence set.

## Scope

- In-scope: semantic result/report types
- In-scope: aggregate dimension scoring
- In-scope: markdown report rendering
- In-scope: verdict thresholds and grouped statistics
- Out-of-scope: persistent report storage
- Out-of-scope: visual dashboard rendering

## Verification Plan

1. The runner produces a structured report from scenario results.
2. The report summary includes standardized dimensions and aggregated scores.
3. The markdown renderer includes summary, grouped statistics, and verdict sections.
4. Focused tests and static checks pass.
