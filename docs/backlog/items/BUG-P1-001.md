# BUG-P1-001: `--variable` 参数替换不生效

> Status: done
> Priority: P1
> Source: E2E Test T2 (Workflow Core)
> Discovered: 2026-06-08
> Completed: 2026-06-08
> Module: `src/commands/run.ts`

## Description

`vectahub run -f <file> --variable "key=value"` 传入变量后，工作流步骤中的 `${key}` 模板变量未被替换。dry-run 文本输出和 `--json` 输出均显示原始模板变量。

## Reproduction

```bash
npx tsx src/cli.ts run --dry-run -f templates/git-commit.yaml --variable "files=." --variable "message=test commit"
```

## Expected

步骤中 `${files}` 被替换为 `.`，`${message}` 被替换为 `test commit`。

## Actual

输出仍为 `git add ${files}` 和 `git commit -m ${message}`，变量未替换。

## Impact

工作流变量注入功能完全不可用，用户无法通过 CLI 参数定制工作流执行。

## Evidence

- `run --dry-run --json -f templates/ci-check.yaml --variable "packageManager=npm"` 输出 `"cli": "${packageManager}"` 未替换
- 文本模式和 JSON 模式均受影响

## Root Cause

`src/commands/run.ts` 的 dry-run 路径在输出步骤后提前 return，从未调用 `engine.execute()`，因此 `interpolateStep()` 从未执行。`--variable` 传入的变量虽然在非 dry-run 路径正确传递给引擎，但 dry-run 路径完全跳过了插值逻辑。

## Scope

- In-scope: `src/commands/run.ts` dry-run 路径变量替换
- Out-of-scope: 意图路由、安全扫描、`src/workflow/interpolation.ts`（权威源码不变）

## Verification Plan

1. 传入 `--variable` 后 dry-run 输出中模板变量被替换
2. `--json` 输出中 `cli` 和 `args` 字段被替换
3. 实际执行（非 dry-run）时变量替换生效

## Completion

### Changes

- `src/commands/run.ts`:
  - 导入 `interpolateStep` 和 `InterpolationContext`
  - 新增 `buildInitialVariables()` 辅助函数（从原内联代码提取）
  - 新增 `toInterpolationContext()` 辅助函数（将 `Record<string, unknown>` 转为 `InterpolationContext`）
  - `--file` dry-run 路径：在输出前对步骤应用 `interpolateStep`
  - NL intent dry-run 路径：在输出前对步骤应用 `interpolateStep`
  - 原 `initialVariables` 内联构建替换为 `buildInitialVariables()` 调用
- `src/commands/run.dry-run.test.ts`:
  - 新增测试：`applies --variable interpolation in dry-run --json for file workflow`

### Verification Evidence

- Typecheck: `npx tsc --noEmit` 通过（0 errors）
- Tests: `npx vitest run src/commands/run.dry-run.test.ts src/workflow/interpolation.test.ts` 全部 27 个测试通过
- 新增测试验证：`--dry-run --json --file --variable` 输出中 `${files}` 被替换为 `.`，`${message}` 被替换为 `test commit`
