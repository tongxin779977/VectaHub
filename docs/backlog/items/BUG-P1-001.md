# BUG-P1-001: `--variable` 参数替换不生效

> Status: open
> Priority: P1
> Source: E2E Test T2 (Workflow Core)
> Discovered: 2026-06-08
> Module: `src/workflow/`

## Description

`vectahub run -f <file> --variable "key=value"` 传入变量后，工作流步骤中的 `${key}` 模板变量未被替换。dry-run 文本输出和 `--json` 输出均显示原始模板变量。

## Reproduction

```bash
npx tsx src/cli.ts run --dry-run -f templates/git-commit.yaml --variable "files=." --variable "message=test commit"
```

## Expected

步骤中 `${files}` 被替换为 `.`，`${message}` 被替换为 `test commit`。

## Actual

输出仍为 `git add ${files}` 和 `git commit -m ${message}`，变量未替换。

## Impact

工作流变量注入功能完全不可用，用户无法通过 CLI 参数定制工作流执行。

## Evidence

- `run --dry-run --json -f templates/ci-check.yaml --variable "packageManager=npm"` 输出 `"cli": "${packageManager}"` 未替换
- 文本模式和 JSON 模式均受影响

## Scope

- In-scope: `src/workflow/` 中变量替换逻辑
- Out-of-scope: 意图路由、安全扫描

## Verification Plan

1. 传入 `--variable` 后 dry-run 输出中模板变量被替换
2. `--json` 输出中 `cli` 和 `args` 字段被替换
3. 实际执行（非 dry-run）时变量替换生效
