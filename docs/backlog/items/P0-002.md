# P0-002: 建立 `OrchestrationPlan` 运行时 schema

> Status: done
> Priority: P0
> Source: Architecture alignment
> Module: `src/orchestration-plan/execution-plan-adapter.ts`, `src/commands/run-dry-run-envelope.ts`
> Completed: 2026-06-08

## Description

`OrchestrationPlan` 类型和 Zod schema已存在于 `src/types/orchestration-plan.ts` 和 `src/orchestration-plan/validator.ts`，但运行时边界（`run --dry-run --json` 输出）仍使用旧的 `ExecutionPlan`，输出 `Record<string, unknown>` 而非类型化的 `OrchestrationPlan`。

需要：
1. 创建 `ExecutionPlan` → `OrchestrationPlan` 的转换函数
2. 在 `buildPlanEnvelope` 中使用转换和验证
3. 将 `RunDryRunResultPlan.plan` 类型从 `Record<string, unknown>` 改为 `OrchestrationPlan`

## Expected

- `run --dry-run --json` 的 plan 输出为符合 Zod schema 验证的 `OrchestrationPlan`
- 转换函数在运行时边界执行 schema 验证
- `ExecutionPlan` 内部使用不变，仅在外部接口层转换

## Scope

- In-scope: `src/orchestration-plan/execution-plan-adapter.ts` 转换函数
- In-scope: `src/commands/run-dry-run-envelope.ts` 类型定义和 builder 函数
- In-scope: `src/orchestration-plan/index.ts` 导出
- Out-of-scope: `ExecutionPlan` 本身的修改
- Out-of-scope: NL capability 系统的内部迁移
- Out-of-scope: `OrchestrationPlan` 类型定义的修改

## Verification Plan

1. `executionPlanToOrchestrationPlan` 转换结果通过 Zod schema 验证
2. `buildPlanEnvelope` 输出包含 `OrchestrationPlan` 结构（`schemaVersion`, `planId`, `tasks`, `safetyReview` 等）
3. Typecheck 通过
4. 所有相关测试通过

## Completion

- `src/orchestration-plan/execution-plan-adapter.ts` (新增):
  - `executionPlanToOrchestrationPlan()` 函数：将 `ExecutionPlan` 转换为 `OrchestrationPlan`
  - 映射 step type → task kind, side effect, executor
  - 映射 command, outputVar, dependency chain
  - 生成 safetyReview, verification, metadata
  - 调用 `validateOrchestrationPlan` 验证转换结果
  - 返回 `ExecutionPlanConversionResult`（plan + validation）

  - `buildPlanEnvelope` 使用 `executionPlanToOrchestrationPlan` 替代 `formatJsonReport`
  - 移除 `formatJsonReport` 导入，添加 `OrchestrationPlan` 和 `executionPlanToOrchestrationPlan` 导入
- `src/orchestration-plan/index.ts`:
  - 导出 `executionPlanToOrchestrationPlan` 和 `ExecutionPlanConversionResult`
- `src/orchestration-plan/execution-plan-adapter.test.ts` (新增):
  - 16 个测试用例覆盖转换逻辑
- `src/commands/run-dry-run-envelope.test.ts`:
