## Description

Agent-delegated orchestration tasks need a policy layer that selects suitable workers, respects explicit delegation targets, and determines when delegated work requires verification.

The delegation policy implementation and tests were already present, but the backlog item file was missing.

## Expected

- Determine whether a task can be delegated.
- Recommend suitable workers based on task kind and worker capability.
- Respect explicit `delegateTo` choices when valid.
- Mark delegated work that requires verification.

## Scope

- In-scope: delegation decision logic
- In-scope: preferred worker handling
- In-scope: delegated verification requirement logic
- Out-of-scope: runtime CLI availability probing
- Out-of-scope: cross-worker load balancing

## Verification Plan

1. Non-agent tasks are rejected for delegation.
2. Agent tasks return suitable-worker recommendations.
3. Invalid `delegateTo` choices are blocked.
4. Delegated verification requirements align with task side effects.
