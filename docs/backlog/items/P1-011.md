> Status: done

## Description

The NL orchestration path needs a reusable semantic acceptance harness that runs multiple user-style inputs against the CLI dry-run path and scores output quality, safety behavior, and contract compliance.

The harness implementation already existed, but it lacked direct regression coverage and backlog tracking. This round added the missing harness tests.

## Expected

- Run multiple scenario expressions through the CLI dry-run path.
- Evaluate safety, output-contract, intent, and usefulness dimensions.
- Produce a structured semantic test report.
- Render a readable markdown summary for review.

## Scope

- In-scope: scenario catalog and runner
- In-scope: aggregate score and pass-rate reporting
- In-scope: markdown report rendering
- Out-of-scope: real online evaluation infrastructure
- Out-of-scope: external dashboard integration

## Verification Plan

1. The runner can execute scenarios and build a structured report.
2. The report includes summary dimensions and pass-rate statistics.
3. Markdown export contains the expected high-level sections.
4. Focused tests and static checks pass.
