# P1-005: 将多步骤 NL plan 转为 WorkflowDraft

> Status: done
> Priority: P1
> Source: Architecture alignment
> Module: `src/orchestration-plan/workflow-draft-converter.ts`, `src/orchestration-plan/doc-task-planner.ts`
> Completed: 2026-06-08

## Description

After planning and safety review, the orchestration path needs a deterministic conversion from `OrchestrationPlan` to `WorkflowDraft`, preserving task order, dependencies, review findings, verification requirements, trace metadata, and snapshot hashes.

The converter and supporting tests are already implemented; the backlog item file was missing.

## Expected

- Convert executable plan tasks into workflow draft steps.
- Skip non-executable reply tasks.
- Preserve delegation semantics for agent tasks.
- Carry safety review, verification, trace, and snapshot metadata into the draft.
- Validate the generated draft when requested.

## Scope

- In-scope: plan-to-draft conversion
- In-scope: delegate and exec step mapping
- In-scope: snapshot hashing and trace carry-over
- In-scope: conversion-time validation helper
- Out-of-scope: execution of the draft
- Out-of-scope: confirmation UI and persistence UX

## Verification Plan

1. Basic exec and delegate tasks convert into the expected draft steps.
2. Reply tasks are skipped.
3. Safety review and trace metadata are preserved.
4. Invalid dependency graphs are rejected by draft validation.
5. Focused tests and typecheck pass.
