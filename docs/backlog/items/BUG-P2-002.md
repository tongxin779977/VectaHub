# BUG-P2-002: `tools eval` 规则引擎覆盖不足

> Status: done
> Priority: P2
> Source: E2E Test T7 (Tools & Templates)
> Discovered: 2026-06-08
> Completed: 2026-06-08
> Module: `src/cli-tools/`, `src/command-rules/`

## Description

`vectahub tools eval` 对 `git push --force` 和 `sudo` 命令返回 ALLOW，但 `vectahub security test` 能正确识别这些为危险命令。两套规则引擎覆盖范围不一致。

## Reproduction

```bash
# tools eval 允许
npx tsx src/cli.ts tools eval "git push --force"
# 输出: 判决: ALLOW

npx tsx src/cli.ts tools eval "sudo apt-get install something"
# 输出: 判决: ALLOW

# security test 拦截
npx tsx src/cli.ts security test "sudo apt-get install something"
# 输出: ❌ DANGEROUS! Severity: critical, Rule: Sudo Command
```

## Expected

`tools eval` 和 `security test` 对同一命令应返回一致的判定结果。危险命令应被两套系统同时识别。

## Actual

`tools eval` 的默认规则集（DEFAULT 模板）仅包含 `block-rm-rf` 等少量规则，缺少 `git push --force`、`sudo`、`curl | bash` 等规则。`security test` 使用独立的 24 条规则数据库，覆盖更全面。

## Impact

用户通过 `tools eval` 评估命令安全性时可能得到错误的 ALLOW 结果，误以为危险命令是安全的。

## Root Cause

`tools eval` 使用的规则引擎（`src/cli-tools/command-rules/`）的 DEFAULT 模板仅包含 8 条 block 规则（`rm -rf`、`chmod 777`、`dd`、`echo > /etc/`），缺少 `sudo`、`git push --force`、`curl|bash` 等关键规则。`security test` 使用的 `src/sandbox/semantic-detector.ts` 有 16 条 `SEMANTIC_DANGEROUS_PATTERNS`，覆盖更全面。两套系统规则未同步。

## Completion

### Changes

- `src/cli-tools/command-rules/templates.ts`:
  - DEFAULT 模板新增 10 条 block 规则，对齐 `SEMANTIC_DANGEROUS_PATTERNS` 覆盖范围：
    - `block-all-sudo`: 阻止所有 sudo 命令
    - `block-git-force-push`: 阻止 git push --force / -f
    - `block-curl-pipe-shell`: 阻止 curl/wget 管道到 shell
    - `block-base64-exec`: 阻止 base64 解码后执行
    - `block-reverse-shell`: 阻止 netcat 反向 shell
    - `block-dev-tcp`: 阻止 /dev/tcp 网络连接
    - `block-suid`: 阻止 SUID/SGID 位设置
    - `block-rm-no-preserve-root`: 阻止 rm --no-preserve-root
    - `block-find-exec-rm`: 阻止 find 配合破坏性 exec
    - `block-read-sensitive-files`: 阻止读取敏感系统文件
  - 保留原有 7 条 allow 规则不变
- `src/cli-tools/command-rules/engine.test.ts`:
  - 新增 16 个测试用例覆盖所有新规则
  - 包含正向测试（危险命令被 block）和反向测试（安全命令仍 allow）

### Verification Evidence

- Typecheck: `npx tsc --noEmit` 通过（0 errors）
- Tests: `npx vitest run src/cli-tools/command-rules/engine.test.ts` 全部 49 个测试通过
- Tests: `npx vitest run src/cli-tools/ src/commands/tools.test.ts` 全部 147 个测试通过
- 新增测试验证：
  - `sudo apt-get install something` → block (block-all-sudo)
  - `git push --force origin main` → block (block-git-force-push)
  - `git push -f origin main` → block (block-git-force-push)
  - `git push origin main` → allow
  - `curl ... | bash` → block (block-curl-pipe-shell)
  - `wget ... | sh` → block (block-curl-pipe-shell)
  - 安全命令（git status/diff/log/add/commit, npm install/run）仍为 allow

## Scope

- In-scope: `src/command-rules/` 默认规则集、`tools eval` 与 `security test` 的规则同步
- Out-of-scope: 安全规则数据库本身（已验证正确）
