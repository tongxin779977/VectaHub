# BUG-P1-003: `resume` 执行记录中 workflowId 为 undefined

> Status: open
> Priority: P1
> Source: E2E Test T3 (Execution Records)
> Discovered: 2026-06-08
> Module: `src/execution/record-manager.ts`

## Description

`vectahub resume <executionId>` 恢复失败执行时报错 "Workflow undefined not found"。执行记录中 `workflowId` 字段未正确保存，导致 resume 和部分 rerun 操作失败。

## Reproduction

```bash
npx tsx src/cli.ts resume exec_20260607_063441_ab0cf33b
```

## Expected

resume 从失败步骤恢复执行，或给出明确的恢复建议。

## Actual

```
❌ 运行时错误: Resume failed: Workflow undefined not found
```

## Additional Evidence

- `rerun exec_20260601_202017_bf2cfb8b` 报 "Workflow wf_49 not found"（工作流已被删除）
- `detail --step 0` 中 `Command: undefined`，说明步骤的命令信息也未正确保存
- 多个执行记录的 workflowId 字段缺失

## Impact

执行恢复（resume）功能完全不可用。rerun 对部分执行也不可用（工作流引用丢失）。

## Root Cause Hypothesis

执行记录写入时 `workflowId` 和步骤 `command` 字段未正确序列化到 JSON 文件中。

## Scope

- In-scope: `src/execution/record-manager.ts` 写入逻辑、执行记录 JSON schema
- Out-of-scope: 工作流删除策略（rerun 引用已删除工作流是预期行为）

## Verification Plan

1. 新执行完成后 `detail <id> --step 0` 显示正确的 Command
2. `resume <failed_id>` 能正确读取 workflowId 并恢复
3. 执行记录 JSON 文件包含 workflowId 字段
