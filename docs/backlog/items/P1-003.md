> Status: done

## Description

The NL orchestration path needs a planner stage that turns routed tasks into an `OrchestrationPlan`, validates the command surface and plan schema, and attaches trace metadata before later review and draft conversion.

This planner flow is already implemented and exercised through orchestration tests, but the backlog item file was missing.

## Expected

- Create an empty `OrchestrationPlan` with schema, metadata, and trace defaults.
- Build a plan from routed capability tasks.
- Block invalid command-surface or schema-invalid plans.
- Attach safety review output before returning a usable plan.

## Scope

- In-scope: empty plan factory
- In-scope: task-to-plan assembly
- In-scope: command-surface validation
- In-scope: runtime plan validation and trace propagation
- Out-of-scope: actual remote LLM inference
- Out-of-scope: semantic ranking of multiple plan candidates

## Verification Plan

1. `createEmptyPlan()` returns the documented base structure.
2. `planFromCapability()` returns `blocked` when command-surface or schema validation fails.
3. Trace ids and audit event ids survive plan creation.
4. Focused orchestration tests and typecheck pass.
