## Description

Delegated worker outputs need a normalized result contract so downstream execution, audit, recovery, and redaction paths can reason over a stable shape instead of raw CLI output.

The worker-result normalizer and tests were already implemented, but the backlog item file was missing.

## Expected

- Normalize raw worker stdout/stderr/exit-code output into a typed result.
- Classify success, failure, and cancelled outcomes.
- Truncate summaries and bound changed-file counts.
- Preserve verification-required metadata for downstream flows.

## Scope

- In-scope: worker result normalization
- In-scope: failure classification
- In-scope: changed-file normalization
- In-scope: summary redaction/truncation
- Out-of-scope: artifact extraction beyond the current empty default
- Out-of-scope: worker-specific rich result schemas

## Verification Plan

1. Successful, failed, and cancelled raw outputs normalize correctly.
2. Long summaries are truncated.
3. Changed-file output is bounded.
4. Focused tests and static checks pass.
