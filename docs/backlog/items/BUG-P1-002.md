# BUG-P1-002: `verify` 使用无效 vitest reporter

> Status: open
> Priority: P1
> Source: E2E Test T2 (Workflow Core)
> Discovered: 2026-06-08
> Module: `src/cli/` (verify command)

## Description

`vectahub verify` 和 `vectahub verify --type test` 执行测试验证时，内部调用 `npx vitest --run --reporter=basic`，但 `basic` 不是 vitest 的有效 reporter 名称，导致 vitest 启动崩溃。

## Reproduction

```bash
npx tsx src/cli.ts verify
npx tsx src/cli.ts verify --type test
```

## Expected

测试验证正常运行并返回测试结果。

## Actual

```
Error: Failed to load custom Reporter from basic
  [cause]: Error: Failed to load url basic (resolved id: basic). Does the file exist?
```

vitest 内置 reporter 为：`default`、`verbose`、`dot`、`junit`、`json`、`tap`。`basic` 不在其中。

## Impact

`verify` 命令的测试验证功能完全不可用。仅 `verify --type typecheck` 可正常工作。

## Root Cause

verify 命令硬编码 `--reporter=basic`，应改为 `--reporter=default` 或 `--reporter=verbose`。

## Scope

- In-scope: verify 命令中 vitest reporter 参数
- Out-of-scope: vitest 配置、其他 verify 类型

## Verification Plan

1. `vectahub verify --type test` 正常运行并返回测试结果
2. `vectahub verify` 全量验证 typecheck + test 均通过
