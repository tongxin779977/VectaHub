# P1-006: 扩展 semantic acceptance cases

> Status: done
> Priority: P1
> Source: Architecture alignment
> Module: `src/semantic-testing/scenarios.ts`, `src/semantic-testing/runner.ts`

## Description

The semantic acceptance harness needed broader case coverage so NL regression checks validate not only direct safe commands and dangerous inputs, but also document-task routing, workflow-draft suggestions, agent delegation, ambiguity handling, and confirmation-required requests.

The base harness and report already existed under `P1-011`, but the scenario set was still too narrow for the acceptance standard. This round expands the case matrix and adds regression checks for the missing categories.

## Expected

- Cover direct safe commands, developer workflows, document tasks, ambiguous requests, dangerous requests, agent delegation, and non-executable reply paths.
- Include workflow-draft expectations for multi-step/document and delegation-style requests.
- Include confirmation-required scenarios in addition to safe and blocked cases.
- Keep semantic scoring compatible with the expanded behavior matrix.

## Scope

- In-scope: semantic scenario matrix expansion
- In-scope: confirmation and workflow-draft scoring support
- In-scope: regression tests for scenario-group coverage
- Out-of-scope: live end-to-end semantic execution against every scenario in CI
- Out-of-scope: UI rendering of semantic reports

## Verification Plan

1. The semantic scenario set includes the missing document-task and agent-delegation groups.
2. The runner can score confirmation-required and workflow-draft outcomes.
3. The regression tests assert the expanded scenario coverage.
4. Focused tests and static checks pass.
