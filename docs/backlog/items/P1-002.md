## Description

Planner and context-building flows need a capability catalog that exposes the currently supported routed capabilities in a normalized summary format.

The builder already exists and returns the known capability metadata plus instantiated runtime capability objects, but the backlog item file was missing.

## Expected

- Return a normalized catalog of known capabilities.
- Expose metadata required by planning and review layers.
- Allow lookup by capability id.
- Expose instantiated current capabilities for routing/runtime use.

## Scope

- In-scope: capability metadata catalog
- In-scope: current capability instantiation
- In-scope: capability lookup by id
- Out-of-scope: dynamic plugin discovery
- Out-of-scope: remote capability registry

## Verification Plan

1. Catalog contains the currently supported capabilities.
2. Every catalog entry includes the normalized summary fields.
3. Runtime capability instances expose `canHandle` and `plan`.
4. Focused tests and typecheck pass.
