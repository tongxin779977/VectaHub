## Description

The orchestration path needs a governance loop for prompt, eval, and rule proposals so feedback can be converted into structured proposal records, reviewed under explicit approval boundaries, and exported into downstream evaluation and policy workflows.

The proposal-record contract, storage, review/apply controls, and exports were already implemented and tested, but the backlog item file was missing.

## Expected

- Define normalized proposal contracts for eval, prompt, and rule proposals.
- Create proposal records from feedback and manual inputs.
- Persist, list, review, apply, reject, and delete proposal records.
- Export proposal summaries and reports for downstream governance loops.

## Scope

- In-scope: proposal record contract
- In-scope: proposal creation from feedback
- In-scope: review/apply/reject governance boundary
- In-scope: reporting and export surfaces
- Out-of-scope: automatic application of approved changes to prompts or rules
- Out-of-scope: remote proposal review service

## Verification Plan

1. Proposal records can be created, persisted, retrieved, and filtered.
2. Review and apply flows enforce explicit approval before application.
3. Reports and exports summarize pending eval, prompt, and rule proposals.
4. Focused tests and static checks pass.
