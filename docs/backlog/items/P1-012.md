# P1-012: 将文档任务接入 OrchestrationPlan / WorkflowDraft

> Status: done
> Priority: P1
> Source: Architecture alignment
> Module: `src/orchestration-plan/doc-task-planner.ts`, `src/commands/parse-doc.ts`
> Completed: 2026-06-08

## Description

Document-derived tasks need to enter the orchestration path through a normalized `OrchestrationPlan` builder, so they can later move into workflow-draft and execution flows instead of staying as ad hoc task lists.

The planner and CLI entry already existed, but the backlog item file and plan-mode regression coverage were missing. This round validated the `parse-doc --plan` path.

## Expected

- Convert parsed document tasks into orchestration tasks.
- Preserve document source metadata and sequencing dependencies.
- Expose the orchestration-plan output from the document command path.
- Support both single-task and multi-task document planning.

## Scope

- In-scope: document task to orchestration task conversion
- In-scope: document source and dependency metadata
- In-scope: `parse-doc --plan` output path
- Out-of-scope: richer source-map extraction beyond current document parsing
- Out-of-scope: direct document-to-execution bypass

## Verification Plan

1. Empty document task sets return a reply response.
2. Single and multi-task document inputs produce document-sourced plans.
3. `parse-doc --plan` returns plan metadata and planned tasks in JSON mode.
4. Focused tests and static checks pass.
