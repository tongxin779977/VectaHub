## Description

The orchestration entry path needs a normalized project context pack so later planning stages can reason about repository state, available scripts, workflow files, installed agents, and current capability exposure.

This builder is already implemented in the codebase and covered by focused tests, but the backlog item file was missing.

## Expected

- Build a `ProjectContextPack` with a stable `schemaVersion`.
- Include package-manager detection and package script discovery.
- Include repository git summary when the current directory is a git repository.
- Include workflow, agent, capability, security-mode, and recent-failure sections.

## Scope

- In-scope: `ProjectContextPack` assembly
- In-scope: package manager and package scripts detection
- In-scope: git repository summary collection
- In-scope: workflow / agent / capability summaries
- Out-of-scope: persistent recent-failure storage
- Out-of-scope: dynamic security-mode policy inference

## Verification Plan
