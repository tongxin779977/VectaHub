# Git Commit Message

> 注释：Git 提交规范。确保变更记录的可读性与规范性。

## 格式 (Format)
```
[模块] 动词 + 做了什么（≤50字，无句号）
```

## 模块名 (Module Names)
`cli` / `nl` / `workflow` / `sandbox` / `cli-tools` / `utils` / `types` / `config` / `test`

## 示例 (Examples)
- `[nl] 添加意图匹配的置信度归一化`
- `[workflow] 修复并行步骤执行顺序问题`
- `[sandbox] 新增 macOS 沙盒检测`
- `[test] 补充 executor 单元测试`
